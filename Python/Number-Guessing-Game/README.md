# 🎯 Proyecto 01: Number Guessing Game

Juego interactivo por consola en Python donde el usuario debe adivinar un número secreto dentro de un rango determinado.

## 🚀 Funcionalidades
- Selección de 3 niveles de dificultad (Fácil, Medio, Difícil) con límite de intentos.
- Pistas dinámicas si el número buscado es mayor o menor.
- Contador de intentos restantes en tiempo real.
- Validación de entradas contra errores (evita fallos si el usuario ingresa texto).
- Opción de reiniciar la partida sin cerrar la terminal.

## 🧠 Aprendizajes aplicados
- Control de flujo y bucles (`while`, `if/elif/else`).
- Generación de números aleatorios con el módulo nativo `random`.
- Manejo de excepciones (`try / except ValueError`) para entrada de datos segura.
- Funciones modulares y punto de entrada `__main__`.
