# 💰 Proyecto 02: Personal Expense Tracker

Aplicación de consola en Python para registrar y gestionar finanzas personales mediante seguimiento de ingresos, gastos y categorías.

## 🚀 Funcionalidades
- Registro de ingresos y gastos con descripción, monto y fecha automática.
- Categorización de gastos (Alimentación, Transporte, Vivienda, etc.).
- Historial completo de movimientos formateado en tabla.
- Cálculo de balance general (Ingresos totales, Gastos totales y Saldo neto).
- Filtro dinámico de gastos por categoría.
- Estadísticas básicas (promedio de gasto, gasto máximo y mínimo).

## 🧠 Aprendizajes aplicados
- Estructuras de datos compuestas: Listas de diccionarios.
- Comprensiones de listas (*List Comprehensions*) para filtrado eficiente.
- Módulo `datetime` para marca temporal de transacciones.
- Uso de funciones integradas (`sum`, `max`, `min`, `lambda`).
- Control de flujo y validación de tipos mediante `try / except`.
